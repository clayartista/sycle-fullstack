# Editable Page UI

Every page below is a normal React component. Edit these files to change page-specific UI without changing the Next.js route structure.

- Landing: `src/components/landing/LandingPage.tsx`
- Guest home compatibility wrapper: `src/pages/GuestHome.tsx`
- Member home: `src/pages/MemberHome.tsx`
- Personalization: `src/pages/Personalization.tsx`
- Processing: `src/pages/Processing.tsx`
- Context confirmation: `src/pages/ConfirmSavedContext.tsx`
- Daily experience: `src/pages/UntukmuHariIni.tsx`
- Reflection: `src/pages/Reflection.tsx`
- Evidence detail: `src/pages/EvidenceDetail.tsx`
- Learn: `src/pages/Pelajari.tsx`
- Healthcare: `src/pages/Healthcare.tsx`
- Facilities: `src/pages/Faskes.tsx`
- Journal list: `src/pages/Journal.tsx`

- Health tracker: `src/pages/HealthTracker.tsx`
- Profile: `src/pages/Profile.tsx`
- Authentication: `src/pages/Auth.tsx`
- Member setup: `src/pages/MemberSetup.tsx`
- Account benefits: `src/pages/AccountBenefit.tsx`
- Shop: `src/pages/Shop.tsx`
- Knowledge Base admin: `src/pages/KnowledgeAdmin.tsx`

Shared site chrome lives in `src/components/Layout.tsx`.
Shared UI primitives live in `src/components/ui/`.
Shared copy for the landing page lives in `src/config/landing.ts`.
