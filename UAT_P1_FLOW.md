# SYCLE UAT — P1/P2/P3 Revision

Use this page with 1–2 candidate users:

`/uat`

## Test protocol

Do not explain the answers before each task. Start timing when the task is read. Record the user's own words and actions.

1. **Value in 10–15 seconds** — Ask: “Menurut kamu SYCLE ini apa?”
2. **Environment relevance** — Ask: “Kenapa cuaca/kelembapan/kualitas udara ditampilkan?”
3. **Action discoverability** — Ask: “Apa yang bisa kamu lakukan sekarang?”
4. **Summary discoverability** — Ask: “Di mana Ringkasan Hari Ini?”
5. **Evidence comprehension** — Ask the user to open the most relevant evidence and find its source.
6. **Health Tracker** — Ask the user to save today's context.

Record:
- completion yes/no;
- seconds to first successful action;
- what the user expected to happen;
- confusing copy/visual elements;
- whether the location permission explanation was understood;
- whether the user understood that AI is not a diagnosis tool.

After the test, save three key findings and one overall note in `/uat`.
